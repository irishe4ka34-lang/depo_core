В Э1 — независимый внешний срез для сравнения, не копия внутреннего остатка.

Связи: CD-UC-047

Владелец факта: ОИС — внешний подтверждённый срез, E40/E17/E64. ЦД — свой актив/пассив и протокол трёхстороннего сравнения. Выдача остатка не означает успешную сверку.

| Поле / группа | Источник | Условие |
|---|---|---|
| Запрос: requestId, заявитель, accountId, период/момент среза | SRC-014 P02036 | По указанному сценарию; транспортное имя/тип OPEN |
| Выписка: statementId/requestId, номер и ID счёта, выпуск, количество и единица, точный T и часовой пояс, источник, формат/версия, хэш, версия расчёта, файл/защищённая ссылка | SRC-014 P02027/P02044/P02092; SRC-016 P00188 | По указанному сценарию; транспортное имя/тип OPEN |
| Плановый остаток: собственный ID, accountId, выпуск, количество, T, часовой пояс, источник, версия формата | SRC-014 P02183/P02187 | operationId/entryId не требуются без новой операции |
| Внутренняя выгрузка ОИС | SRC-014 P03427 | Не является внешним контрактом ЦД; право получения и самостоятельный формат обмена OPEN |
| Протокол ЦД: выпуск, внешнее место, T, три сравниваемые величины, расхождения/caseId/приоритет | SRC-022 P04315–04320 | Внутренний результат ЦД, не поля выписки ОИС |

Повтор выдаёт тот же E40/statementId; повтор планового E17 сохраняет ID и T. Ни один отчёт не создаёт E14/E15.

Плановый остаток возможен без движения; отсутствие подтверждённого источника не разрешает выдать неподтверждённый остаток.

Точное T и часовой пояс обязательны; нет данных — нет доказанного равенства. Внешний остаток = актив ЦД = сумма пассивов сравниваются, не складываются.

Внешняя выписка ОИС по счёту НД самого ЦД содержит агрегат НД; она не является клиентской выпиской CD-UC-056 и не заменяет детализацию депонентов в ЦД. Доступ проверяется по конкретному счёту/периоду; внутренний E64 имеет другую область прав.

OIS-Q-27/56, OD-06/14: проверить штатные отчёт/выгрузку/канал до нового экрана; дополнительные поля и право получения требуют утверждения

S44: календарь, часовой пояс, точный конец дня, опоздавшие события, финальность среза и версия исторических данных

Конкурентное формирование и запись/коррекция: нужен согласованный консистентный исторический срез, алгоритм не задан

Доступ к нескольким счетам E64 не предоставляется ЦД автоматически

Источники: SRC-014 P02021–02093/P02168–02242/P03420–03429; SRC-016 правило внешней стороны (источник ОИС)/R-46; SRC-017 S44 P01806–01862; SRC-022 P04313–04320.
