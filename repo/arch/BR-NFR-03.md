Целевые показатели доступности, RTO и RPO должны быть утверждены владельцем бизнеса до завершения архитектуры; предварительные значения из технического ТЗ используются для оценки.

Источник: SRC-018:P00932; SRC-018 table 20 row 4. Связь с процессами: сквозное требование; самостоятельный UC не заменяет его проверку.

Предложение измерения: Доступность за согласованное окно, время восстановления и допустимая потеря данных. Метод проверки: Зафиксировать начало и конец недоступности, определение успешной операции и границы измерения RTO/RPO.

Предлагаемый владелец: Владелец бизнеса.

OPEN: Утвердить численные SLO/RTO/RPO и допустимые окна для отдельных контуров.
