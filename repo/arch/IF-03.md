В Э1 — приём, дедупликация и передача события единственному обработчику.

Связи: CD-UC-037, CD-UC-046

Владелец факта: ОИС — исходное событие подтверждённой книги/статуса; ЦД — приём, маршрутизация и локальный результат обработчика. Ни ACK, ни событие не являются записью ЦД.

| Поле / группа | Источник | Условие |
|---|---|---|
| outboundEventId, тип, accountId, источник, версия схемы/S42, контрольный остаток | SRC-014 P02187/P02225–02240 | По указанному сценарию; транспортное имя/тип OPEN |
| operationId/entryId | SRC-014 P02187 | Только если событие вызвано соответствующей операцией/записью; не обязательно для среза без движения |
| Содержание/контрольная сумма; попытки доставки; транспортный ACK; отдельная деловая квитанция ЦД | SRC-014 P02239–02241 | По указанному сценарию; транспортное имя/тип OPEN |
| eventId, версия, correlationId и результат обработчика | SRC-022 P04227–04230 | Имена со стороны ЦД; соответствие outboundEventId ↔ eventId требует контракта |

Повтор передаёт тот же outboundEventId, не повторяет E14/E15. Смена профиля не создаёт новое событие учётного факта.

Потерянный ACK не доказывает отсутствие обработки ЦД. ACK получен без деловой квитанции — обработка у ЦД не подтверждена.

ЦД устраняет повтор и передаёт одному ответственному процессу; учёт меняют соответствующие UC.

Для зачисления ЦД достоверно подтверждает внешнее зачисление и сопоставляет получателя; агрегат ОИС не распределяется произвольно.

OD-13/22: идентификация получателя, типы событий и матрица маршрутизации, окончательные статусы

Соответствие eventId/outboundEventId и correlationId, порядок конфликтующих/опоздавших событий, восстановление пропусков

Конкуренция повторов события, ответа по статусу и сверки: один локальный учётный эффект; механизм inbox/уникальных ограничений лишь возможное PROPOSAL, не утверждён

Источники: SRC-014 P02168–02242; SRC-022 P03393–03400/P04223–04230; SRC-016 правило внешней стороны (источник ОИС)/R-40.

1.4 · Профиль РЦД — цель. РЦД: событий нет, используется опрос 2.5–2.6 не чаще раза в минуту; курсора нет.
