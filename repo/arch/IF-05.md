В Э1 — введённое подтверждение или ожидание; внутренний экран и решение сотрудника ОИС не создаются.

Связи: Владелец факта: Официальный источник — проверяемые сведения. Операционист ОИС — факт проверки и доказательства. Уполномоченный сотрудник/контролёр — решение; система хранит заявленную и подтверждённую роль раздельно.

| Поле / группа | Источник | Условие |
|---|---|---|
| Регистрационные сведения заявителя, заявленная роль | SRC-014 P00474/P00529 | По указанному сценарию; транспортное имя/тип OPEN |
| Источник/проверяемая ссылка либо выписка; дата и точное время; результат; проверивший сотрудник | SRC-014 P00463/P00478; SRC-016 P00172 | По указанному сценарию; транспортное имя/тип OPEN |
| Подтверждённая роль и связь с ЮЛ/счётом; состояние проверки; мотивированное решение | SRC-014 P00478/P00511–00518/P00535 | По указанному сценарию; транспортное имя/тип OPEN |
| Версия настройки S43, конкретное дело E62 и решение E29 | SRC-017 P01755–01760 | Конфигурация и факт проверки раздельны |

Это ручная граница; API реестра не входит в первый кейс. S42 к проверке реестра не применяется.

Недоступность источника — ожидание проверки; подтверждённый отрицательный результат — мотивированное решение. Противоречивые сведения требуют выяснения.

Неподтверждённая роль не открывает счёт. Сигнал прекращения допуска не изменяет счёт автоматически; решения выполняются отдельными UC.

PROPOSAL (не подтверждённое требование): повторная проверка получает собственные доказательства и момент; старое доказательство не заменяется новым задним числом. Механизм версий требует согласования.

OIS-OD-05/14 и Q-52/53/55: перечень официальных источников, допустимое доказательство, периодичность и срок проверки, ответственность и право решения

Срок актуальности проверки, разрешение противоречий, банкротство/реестровая запись как разные факты и повторный допуск

Два параллельных решения/проверки: актуальная версия дела, полномочия и контроль подтверждения — OPEN

Транспортные ACK, retry API, схемы запросов и внешние endpoint для этой границы неприменимы; не создавать их

Источники: SRC-014 P00463/P00474–00478/P00511–00518; SRC-016 P00032/P00172; SRC-017 P01673/P01755–01760.

1.4 · Профиль РЦД — цель. РЦД: не применимо.
