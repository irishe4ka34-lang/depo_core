Названия относятся к объекту конкретного UC; это проектные состояния, не утверждённые технические коды. Условия ветвления — КЭ1-02 § UC-047. Несколько исходов требуют критерия выбора; произвольный выбор запрещён.

| Участок сценария | Переход или результат |
|---|---|
| Шаг 1 | Нет → Сверка создана |
| Шаг 2 | Сверка создана → Источники собраны |
| Шаг 3 | Источники собраны → На сопоставлении |
| Шаг 4 | На сопоставлении → Сравнено: без расхождений / С расхождениями |
| Шаг 5 | С расхождениями → Требует расследования; без расхождений → Сверено |
| Шаг 6 | Сверено / Требует расследования → Протокол утверждён |
| А1, шаг 4 | На сопоставлении → Сверено → Протокол утверждён. |
| А2, шаг 4 | На сопоставлении → С расхождениями / Ожидает события; кейс открыт. |
| А3, шаг 5 | С расхождениями → Критическое расхождение; UC-048, запрет новых рискованных действий. |
| А4, шаг 6 | Протокол утверждён → Новый запуск / Повторная сверка; связь с прежним runId. |
| И1, шаг 2 | Сверка создана → Источник недоступен; «Сверено» не выставляется, эскалация. |
| И2, шаг 3 | Источники собраны → Ошибка сопоставления; кейс, нельзя принять ложное равенство. |
| И3, шаг 5 | Критическое расхождение → Инцидент; операции ограничиваются доступным контуром до подтверждения меры. |
| И4, шаг 6 | Возвращается тот же runId и протокол либо новая явно связанная версия, без потери расхождений. |
