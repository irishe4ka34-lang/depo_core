Названия относятся к объекту конкретного UC; это проектные состояния, не утверждённые технические коды. Условия ветвления — КЭ1-02 § UC-056. Несколько исходов требуют критерия выбора; произвольный выбор запрещён.

| Участок сценария | Переход или результат |
|---|---|
| Шаг 1 | Нет → Черновик запроса |
| Шаг 2 | Черновик → Принят |
| Шаг 3 | Принят → Формируется |
| Шаг 4 | Формируется → Готова |
| Шаг 5 | Готова → Предоставлена |
| А1, шаг 1 | Черновик → Принят в допустимых пределах. |
| А2, шаг 3 | Принят → Готова → Предоставлена. |
| А3, шаг 5 | Готова → Предоставлена вручную. |
| И1, шаг 1 | Черновик → Отказано; сведения не раскрываются. |
| И2, шаг 4 | Формируется → Исключение; UC-048, выдача остановлена. |
| И3, шаг 5 | Готова → Ожидает выдачи; не считать доставленной. |
