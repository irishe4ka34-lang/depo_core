Названия относятся к объекту конкретного UC; это проектные состояния, не утверждённые технические коды. Условия ветвления — КЭ1-02 § UC-046. Несколько исходов требуют критерия выбора; произвольный выбор запрещён.

| Участок сценария | Переход или результат |
|---|---|
| Шаг 1 | Нет → Получено |
| Шаг 2 | Получено → На проверке → Проверено |
| Шаг 3 | Проверено → Маршрут определён |
| Шаг 4 | Маршрут определён → Передано обработчику |
| Шаг 5 | Передано обработчику → Обработано / Исключение |
| А1, шаг 3 | Проверено → Уже обработано; исходный статус сохраняется. |
| А2, шаг 3 | Проверено → Ожидает предыдущее → Маршрут определён / Исключение. |
| А3, шаг 4 | Маршрут определён → Исключение → Повтор после разрешения. |
| А4, шаг 5 | Передано обработчику → Принято в разбор; бизнес-исход открыт. |
| И1, шаг 2 | Получено → Отклонено / Карантин; никаких изменений учёта. |
| И2, шаг 3 | Проверено → Конфликт ID; расследование, автоматическая перезапись запрещена. |
| И3, шаг 4 | Маршрут определён → Ожидает подтверждения; проверка его результата по eventId до повтора. |
| И4, шаг 5 | Событие остаётся Обработано / Исключение; доставка квитанции повторяется отдельно. |
