id: STATE-UC-027
title: Переходы UC-027
summary: Названия относятся к объекту конкретного UC;
status: перенесено как есть
origin: КЭ1-04 Правила § STATE-UC-027
---
Названия относятся к объекту конкретного UC; это проектные состояния, не утверждённые технические коды. Условия ветвления — КЭ1-02 § UC-027. Несколько исходов требуют критерия выбора; произвольный выбор запрещён.

| Участок сценария | Переход или результат |
|---|---|
| Шаг 1 | Документы получены сотрудником; карточка ещё не зарегистрирована. |
| Шаг 2 | Проверка сотрудником положительна → ручной ввод; иначе И1 без успешной регистрации. |
| Шаг 3 | Введённые сведения → На проверке; автоматического извлечения нет. |
| Шаг 4 | На проверке → Сопоставлен при успешной системной валидации; ошибки/конфликты → А2 или И2. |
| Шаг 5 | Сопоставлен → Зарегистрирован после подтверждения операционистом и сохранения единственной карточки. |
| Шаг 6 | Зарегистрирован → Зарегистрирован; показ результата и аудит, без обязательной квитанции ОИС. |
| А1, шаги 4–5 | Тождественный повтор → прежний результат и ID; второй карточки нет. |
| А2, шаг 4 | На проверке → Требует сопоставления; далее UC-028. |
| А3, последующее изменение | Прежняя версия сохраняется; допустимое обновление или разбор определяется после проверки. Автоматического перезаписывания нет; критерий выбора открыт. |
| А4, шаг 4 | На проверке → Сопоставлен по утверждённой версии справочника. |
| И1, шаги 1–2 | Успешная регистрация исключена при отсутствующем/некорректном комплекте или неподтверждённой ручной проверке. Точный статус и доработка — UC027-Q2. |
| И2, шаг 4 | Ошибки обязательных данных, конфликт ID/версии или отсутствие полномочий → нет успешной регистрации и перезаписи; ошибки ввода/разбор/аудит отказа по КЭ1-02 UC-027. |
| И3, шаг 5 | Исход сохранения выясняется; повтор по прежнему ключу без дубля. |
| И4 прежней редакции | Неприменима к ручному пути: квитанция ОИС не требуется. Сохранено соответствие прежней ветви. |
