Названия относятся к объекту конкретного UC; это проектные состояния, не утверждённые технические коды. Условия ветвления — КЭ1-02 § UC-057. Несколько исходов требуют критерия выбора; произвольный выбор запрещён.

| Участок сценария | Переход или результат |
|---|---|
| Шаг 1 | Нет → Запрос принят |
| Шаг 2 | Запрос принят → Данные собраны |
| Шаг 3 | Данные собраны → Карточка готова |
| Шаг 4 | Карточка готова → Доступна |
| Шаг 5 | Доступна → Просмотрена / Справка выдана |
| А1, шаг 3 | Карточка готова → Доступна с предупреждением. |
| А2, шаг 3 | Карточка готова → Доступна с историей. |
| А3, шаг 5 | Доступна → Предоставлена по кейсу. |
| И1, шаг 1 | Запрос → Отказано; детали не раскрываются. |
| И2, шаг 2 | Запрос принят → На проверке; нет ложного финального статуса. |
| И3, шаг 5 | Карточка доступна; справка → Ошибка, повтор по requestId. |
