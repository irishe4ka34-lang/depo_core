Названия относятся к объекту конкретного UC; это проектные состояния, не утверждённые технические коды. Условия ветвления — КЭ1-02 § UC-037. Несколько исходов требуют критерия выбора; произвольный выбор запрещён.

| Участок сценария | Переход или результат |
|---|---|
| Шаг 1 | Нет → Событие принято |
| Шаг 2 | Событие принято → На сопоставлении |
| Шаг 3 | На сопоставлении → Подтверждено ОИС |
| Шаг 4 | Подтверждено ОИС → Отражено в ЦД |
| Шаг 5 | Отражено в ЦД → Сверено / Расхождение |
| А1, шаг 2 | Событие принято → Уже обработано; позиция не меняется. |
| А2, шаг 2 | На сопоставлении → Требует разбора → Подтверждено ОИС / Исключение. |
| А3, шаг 3 | На сопоставлении → Расхождение; проводки нет. |
| А4, шаг 5 | Отражено в ЦД → Расхождение; разбор UC-047–049. |
| И1, шаг 1 | Событие не принято / Ожидает финала; позиция не меняется. |
| И2, шаг 3 | На сопоставлении → Исход неопределён; запрос статуса/кейс без зачисления. |
| И3, шаг 4 | Подтверждено ОИС → Требует сверки; повтор по внешнему ID выясняет итог и не дублирует проводку. |
| И4, шаг 5 | Учётная запись сохраняет Сверено; доставка → Повтор UC-015. |
