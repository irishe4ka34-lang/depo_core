## 2.2 Состав записи о депоненте {#2.2}
Сведения по 115-ФЗ ст.7 ([[NR-115-7]]) и сведения для уникального кода; если от имени депонента действует **представитель — сведения, позволяющие идентифицировать представителя**.

## 2.3 Статус и тип {#2.3}
Резидент или нерезидент (173-ФЗ); тип — ЮЛ, ИП или ФЛ; гражданство или его отсутствие. Тип лица используется в номере счёта ([[NR-892-APP#number]]).

## 2.4 Уникальный код депонента {#2.4}
Шестнадцатеричная строка 256 бит — результат хэш-функции **ГОСТ Р 34.11-2012** от конкатенации сведений **без разделителей** в указанном порядке:

| Категория | Сведения (в этом порядке) |
|---|---|
| Резидент — ФЛ (не ИП) | дата рождения ДД.ММ.ГГГГ; ИНН; серия и номер паспорта РФ |
| Резидент — ИП | дата регистрации в ЕГРИП ДД.ММ.ГГГГ; ОГРНИП; рег. номер страхователя в СФР |
| Резидент — ЮЛ | дата регистрации в ЕГРЮЛ ДД.ММ.ГГГГ; ОГРН; рег. номер страхователя в СФР |
| Нерезидент — ЮЛ | дата регистрации в иностранном реестре; TIN или аналог; код страны по ОКСМ (995/996 — международная компания, 998 — международная организация, 999 — страна неизвестна) |
| Нерезидент — ФЛ (в т.ч. иностранный ИП) | дата рождения; TIN или аналог; код страны гражданства по ОКСМ |
| Лицо без гражданства | дата рождения; ФИО по документу, удостоверяющему личность |

## 2.5–2.7 Прочие сведения {#2.5}
Банковские реквизиты для выплат по цифровым правам (2.5); номера всех счетов депонента (2.6); номера, даты заключения и прекращения договоров цифрового учёта (2.7).

## 2.10 Источник записей {#2.10}
Записи вносятся по документам и сведениям, полученным при идентификации депонента **и его представителей** по 115-ФЗ ст.7, или из государственных информационных систем.

## 2.11 Изменение кода {#2.11}
Если меняются сведения, входящие в код, ЦД **в тот же день** присваивает новый код и сохраняет прежние.
