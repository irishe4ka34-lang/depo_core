Решения по [[UC-037]]:

1. **Два основания.** Запись на AA — по документу ОИС о зачислении на счёт N ([[NR-892-11#11.1]]); запись на счёт клиента — по поручению депонента на зачисление ([[NR-892-9#11.9]]), зарегистрированному как [[K11]] вида «ввод». У [[K07]] добавлено поле `instruction_id`.
2. **Финальность ([[OD-22]]).** Проводка — по подписанному УКЭП отчёту ОИС об исполненной операции; выписка ОИС подтверждает её на ежедневной сверке, несовпадение — дело. Обязательные поля — в [[UC-037]]. Аналог — подтверждение расчётов sese.025 в НРД и Euroclear; сообщения о ходе исполнения финальность не доказывают.
3. **Получатель ([[MODEL-Q06]]).** Только по поручению; сопоставление автоматическое по выпуску, счёту N, количеству, отправителю и ссылке. Нет поручения или подходят два — дело операционисту. Не решено до конца рабочего дня, следующего за подтверждением ОИС, — счёт неустановленных лиц XY ([[REV-R27]]). Одно движение — одному получателю.
4. **Повтор ([[MODEL-Q03]], вариант «а»).** Ключ эффекта — «ОИС + ID операции ОИС + вид эффекта», хранится бессрочно.
5. **Отчёт.** Личный кабинет ЦД; e-mail — если указан в договоре. Сроки — по [[NR-892-14#14.2]]. Клиентов брокера информирует брокер.
