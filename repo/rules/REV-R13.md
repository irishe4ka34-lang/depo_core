**Правило** = условие над полями карточки K03 и составляющих K23 + список полей, обязательных при истинном условии. Безусловные реквизиты профиля (колонка О в [[NR-282-7#profiles]]) — правило с условием «всегда». Набор правил версионируется в [[CFG-CD-D-09]].

**Когда проверяется.** При сохранении карточки и при переходе в `MAPPED`.

| Исход | Когда | Что дальше |
|---|---|---|
| PASS | все требуемые поля заполнены и прошли проверку формата | карточка может перейти в MAPPED |
| MISSING | не хватает полей | перечень полей операционисту; карточка в NEEDS_REVIEW |
| UNDETERMINED | условие нельзя вычислить — нет исходного поля | карточка в NEEDS_REVIEW |

Результат и версия правил сохраняются как доказательство (`admission_check_id`). Новая версия правил не меняет допущенные карточки; перепроверка — отдельное действие с аудитом.

**Всегда обязательны по 892-П** ([[NR-892-3#3.7]]): вид цифровых прав (ЦФА / УЦП / ГЦП), виды удостоверяемых прав, сведения об эмитенте, уникальный идентификатор по п.3.10, наименование и ИНН оператора ИС.
