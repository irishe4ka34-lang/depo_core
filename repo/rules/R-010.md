ЦД раскрывает сведения только адресату с подтверждёнными полномочиями и в объёме законного основания. Третьим лицам — только по письменному указанию депонента ([[NR-892-14#14.5]]).

**Как применяется.**

- Доступ проверяется по конкретному счёту и периоду.
- Выписка ОИС по счёту N нашего ЦД показывает агрегат и не заменяет выписку депоненту ([[UC-056]]).
