title: Режим посредника
summary: "Брокер без статуса ЦД — представитель на счёте O клиента; доверительный управляющий — счёт T на своё имя; цифровой депозитарий — счёт N на своё имя."
sources: [NR-282-22#nominee, NR-892-9#9.1]

**Условие.** Заявку на открытие подаёт посредник или заявка касается счёта посредника.

**Действие.** Режим определяется статусом посредника, а не его желанием:

| Статус посредника | Какой счёт и на чьё имя | Флаг CD-D-08 на старте |
|---|---|---|
| Брокер без статуса цифрового депозитария | O на имя **клиента**, брокер — представитель ([[REV-R18]]) | включён |
| Доверительный управляющий | T на имя **управляющего** | выключен |
| Цифровой депозитарий (в реестре ЦБ) | N на имя **этого ЦД** ([[NR-282-22#nominee]]) | выключен |
| Обменник | посредником не является; клиент открывает O сам | — |

**Исключения.** Нет.

**Отказ.** Заявка на N от участника без статуса цифрового депозитария — «Отклонена: номинальным держателем может быть только цифровой депозитарий».

**Пример.** Брокер «Альфа» без статуса ЦД просит счёт N → отказ; тот же брокер подаёт заявку клиента Иванова → счёт `OXXXX6430…` на имя Иванова, `servicing_agent_id` = «Альфа».
