**Хранение.** Количество хранится целым числом минимальных единиц версии выпуска, тип не уже NUMERIC(38,0). Для человека: `units / 10^quantity_scale`.

**Параметры выпуска** (K03):

- `quantity_scale` — 0–18; для ЦФА — из решения о выпуске, для ЦВ — из справочника РЦД (`amountPrecision`, [[NR-892-3#3.3]]);
- `min_step` — минимальный шаг в минимальных единицах, если решение о выпуске задаёт шаг крупнее;
- без `quantity_scale` выпуск к операциям не допускается.

**Ограничение 892-П.** Дробная часть не может быть мельче допустимой во внешней системе ([[NR-892-8#8.2]]).

**Операции.** Количество, не кратное `min_step`, отклоняется с причиной — учёт не округляет. Перевод из титульной единицы ЦВ — умножением на множитель; дробный остаток — отказ. Количества разных выпусков не сравниваются.

| Актив | Ориентир scale |
|---|---|
| ЦФА на практике | 0 (целые штуки) |
| BTC | 8 |
| токены Ethereum | до 18 |
| паи ПИФ | не менее 5 |
