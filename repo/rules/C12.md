Новая связь [[K04]] «выпуск ↔ наш счёт N у оператора» не создаётся, если уже есть действующая (не заменённая) связь, которая ей противоречит.

**Примеры конфликта.**

- Выпуск X уже привязан и готов (`READY`) к **другому** нашему счёту N у того же оператора — два места учёта одного выпуска; при зачислении непонятно, на какой счёт активов писать покрытие.
- Связь «тот же счёт N + тот же выпуск» уже существует — дубль; вместо новой связи меняется версия существующей.
- Вид счёта не подходит выпуску: счёт N обычный, а выпуск должен учитываться на торговом, или наоборот.
- Счёт N в ЦД зарегистрирован как приостановленный или закрытый.
- Номер счёта N уже связан со счётом активов другого оператора — по п.10.2 на каждый счёт N свой AA.

**Что не конфликт.** Один счёт N и несколько выпусков: на каждый выпуск — своя связь.

**Результат.** Связь не создаётся, статус «Конфликт», причина показывается операционисту; ручная замена внешнего ID запрещена.
