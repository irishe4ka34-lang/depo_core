Ключ однократного зачисления: система-источник, ID внешней операции и вид эффекта. Два eventId одного внешнего зачисления не создают двух операций. Неизвестный ID или противоречивое содержимое блокируют проведение.

**Профиль РЦД.** Источник — РЦД, ID — receiptId; два ответа с разным updateNo по одному receiptId не дают двух операций.
